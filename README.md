# Real Estate Webpage

A responsive real estate landing page developed using HTML and CSS. The webpage showcases a modern property website layout with a clean user interface suitable for real estate agencies, property listings, and housing businesses.

---

## Features

- Responsive webpage design
- Modern landing page layout
- Clean and organized user interface
- Property showcase section
- Attractive typography and styling
- Beginner-friendly project structure
- Cross-browser compatible

---

## Technologies Used

- HTML5
- CSS3

---

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Thiru2006/RealEstate-Webpage.git
```

### Navigate to the project

```bash
cd RealEstate-Webpage
```

### Run the project

Open `index.html` in your preferred web browser.
